# Purpose

This document specifies mandatory writing style rules, document structure patterns, terminology conventions, screenshot embedding rules, and accessibility standards for all user-facing documentation within the AI Rural Root Cause Discovery System.

---

# Style & Writing Guidelines

### Rule 1: Action-Oriented Task Headings
User guide sections **MUST** use active, task-oriented verbs (e.g., "Submitting a Rural Survey", "Reviewing AI Evidence Features") rather than passive nominalizations ("Survey Submission Procedure").

### Rule 2: Clear User Persona Isolation
Every user guide **MUST** explicitly state the target user persona, required RBAC permissions, and pre-requisites at the start of each procedure.

### Rule 3: Visual Step Demarcation
Step-by-step procedures **MUST** utilize numbered lists, bold UI element names (e.g., **Click [Submit Survey]**), and UI text matching actual application labels.
