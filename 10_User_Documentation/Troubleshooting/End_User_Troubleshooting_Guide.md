# Purpose

This guide assists end users, field officers, and government officials in diagnosing and resolving common user interface, authentication, network sync, and browser errors encountered while using the AI Rural Root Cause Discovery System.

---

# Common Error Scenarios & Resolution Matrix

| Issue / Symptom | Possible Cause | Self-Service Resolution Steps | Escalation Path |
|-----------------|----------------|-------------------------------|-----------------|
| **Login Error: "Invalid Credentials"** | Incorrect password or expired session | Click **[Forgot Password]** or reset password via Government SSO Portal | Helpdesk Support |
| **"Session Expired (401 Unauthorized)"** | Token expired after 60 min inactivity | Refresh page (`Ctrl + F5`) and log back in | N/A |
| **Mobile App Sync Warning** | Low cellular network coverage | Move to an area with active 4G/5G or Wi-Fi connectivity and tap **[Sync Now]** | Field Tech Lead |
| **Dashboard Map Tiles Not Loading** | WebGL browser support disabled | Enable WebGL in browser settings (Chrome: `chrome://settings/system`) | IT Helpdesk |
| **PDF Report Generation Fail** | Popup blocker blocking download | Allow popups for domain `https://csp.gov.in` | IT Helpdesk |
