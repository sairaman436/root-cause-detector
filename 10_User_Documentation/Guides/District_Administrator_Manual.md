# Purpose

This manual provides district administrative leaders with procedures for managing district user accounts, assigning survey territories to field officers, auditing local survey submissions, tracking project implementation timelines, and generating monthly district progress reports.

---

# Administrative Tasks

### Task 1: Assigning Field Officer Survey Territories
1. Navigate to **Admin Portal -> Territory Management**.
2. Select target **Sub-District / Block**.
3. Select Field Officer name from user directory.
4. Check assigned village checkboxes and click **[Save Territory Mapping]**.

### Task 2: Generating Monthly District Performance Summaries
1. Navigate to **Reports -> District Executive Summary**.
2. Select Date Range (e.g., `2026-06-01` to `2026-06-30`).
3. Select Export Format (**PDF** / **Excel**).
4. Click **[Generate Report]**.
