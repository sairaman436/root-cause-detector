# Engineering Plan Template

## Purpose

Use this template for milestone or feature implementation plans.

## Required Content

### Objective

State the outcome and scope boundary.

### Non-Goals

State what must not be implemented.

### Impacted Areas

List modules, APIs, schemas, events, infrastructure, docs, and tests.

### Implementation Plan

Break work into ordered, reviewable steps.

### Dependencies

List internal and external dependencies.

### Failure Modes

Define expected failures and handling strategy.

### Security And Privacy

Define authorization, data classification, audit, and secret impact.

### Observability

Define logs, metrics, traces, dashboards, and alerts.

### Validation

List exact test and build commands.

### Rollback

Describe rollback or roll-forward path.

## Anti-Patterns

- Planning future milestone work inside current scope.
- Omitting validation commands.
- Ignoring operational impact.
- Treating security as a later review.
