# Multimodal Real-World Evaluation Report

## Scope

This milestone adds an evaluation-only workspace around the existing live
vision-to-decision pipeline. It does not create training candidates, modify
datasets or evaluation sets, submit governance decisions, or call the
authenticated human-evaluation API.

## Evaluation Lab

- Screen: `Multimodal Evaluation Lab`
- Artifact storage: browser-local `localStorage`, with JSON export
- Stored content: image metadata, selected domain, question, actual pipeline
  result, optional human-entered scores, failure class, flags, and comments
- Automatic scores: none
- Training/dataset integration: none
- Comparison: saved-run table with explicit `Not scored` values for missing
  human scores

The selected domain is recorded as an evaluation label only. The UI does not
assume that an image belongs to the selected domain.

## Human Review Status

Six human-review panels were displayed and saved locally as `UNSCORED`:
the original Agriculture run, Agriculture 2, Healthcare, Energy, Education,
and Livelihoods. No scores, failure labels, unsupported-claim flags, or
comments were added automatically. Water/sanitation has no reviewable result.

## Bottleneck

The observed bottleneck is **evidence relevance and vision-to-retrieval
alignment**, not raw image inference. Vision returned for six of seven
attempts, but three domain cases produced retrieval queries that returned no
governed evidence. Healthcare also produced a potentially incorrect
facility-type observation, and its recommendation was correctly stopped by
grounding. When the evidence and validated root cause aligned, the second
Agriculture case produced a grounded recommendation.

The weakest measured stage is therefore retrieval/evidence relevance, with a
secondary vision classification issue in Healthcare. Human rubric scores are
not available yet, so this conclusion is based only on structural outcomes,
grounding gates, and observed pipeline termination points.

## Recommended Next Milestone

Complete explicit human scoring for the six saved artifacts, then run a
separate evidence-coverage and query-alignment investigation for the three
retrieval failures. Investigate the Healthcare observation mismatch as a
vision-quality case. Do not promote these local artifacts into training data
or modify the governed datasets without a separate approved workflow.
