# Root Cause Evaluation

## Purpose

Defines evaluation gates for the root-cause intelligence engine.

## Current Gates

Unit tests validate fact/evidence category separation, causal graph generation, alternative hypotheses, contradiction detection, insufficient-evidence uncertainty, and confidence interpretation.

## Metrics

The evaluation tracks root-cause identification quality, evidence groundedness, citation accuracy, alternative hypothesis quality, contradiction detection, uncertainty detection, and human agreement. Causal accuracy is not claimed without expert validation.

## Synthetic Scenarios

The test plan covers water shortage, low crop yield, school attendance decline, unemployment, conflicting evidence, insufficient evidence, and multiple plausible root causes. All scenario data is synthetic and must not be presented as real statistics.
