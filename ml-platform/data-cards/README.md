# Data Cards

## Purpose

Stores governed documentation for datasets used by analytics, AI, and MLOps workflows.

## Why It Exists

Data cards capture ownership, intended use, quality limitations, privacy classification, retention, lineage, and approval status before datasets are used for training, evaluation, retrieval, or reporting.

## Architecture Fit

This directory supports data governance, AI governance, model approval, and auditability across the approved MLOps architecture.

## Implementation Notes

Do not store datasets here. Store only reviewed metadata documents and templates that describe governed datasets.
