# Security Policy

## Purpose

Defines how security issues, secrets exposure, dependency risks, and AI safety concerns are handled in this repository.

## Why It Exists

The platform will process sensitive public-sector evidence, AI outputs, reports, and governance artifacts. Security handling must exist before feature implementation begins.

## Architecture Fit

This file operationalizes the approved Security & Governance Architecture for repository-level work.

## Reporting

Report suspected vulnerabilities, leaked secrets, unsafe AI behavior, or supply-chain risks to the security owner before public disclosure.

## Required Handling

- Rotate exposed secrets immediately.
- Preserve audit evidence.
- Open a private security issue or incident record.
- Assess affected environments and artifacts.
- Add regression checks where possible.
