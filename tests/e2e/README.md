# End-to-End Tests

## Purpose

Contains user-flow and system-flow tests that validate complete platform behavior.

## Why It Exists

End-to-end tests provide release confidence for workflows that cross frontend, backend, AI services, data stores, queues, and reporting boundaries.

## Architecture Fit

These tests belong at the outermost validation layer and should cover only high-value production journeys to keep feedback useful and maintainable.

## Implementation Notes

Milestone 1 establishes the boundary only. Add end-to-end tests after user-facing workflows exist.
