# Purpose

This document defines the enterprise-standard Feature Engineering Dataset used during the feature preparation stage of the AI Rural Root Cause Discovery System.

The objective is to ensure that engineered features are consistent, reproducible, explainable, statistically valid, and suitable for machine learning model development while maintaining complete traceability to their originating business data.

---

# Objectives

The Feature Engineering Dataset shall:

- Standardize engineered feature creation.
- Improve predictive performance.
- Reduce feature redundancy.
- Maintain feature consistency.
- Enable reproducible preprocessing.
- Support explainable AI.
- Preserve business meaning.
- Support feature versioning.
- Facilitate feature quality monitoring.
- Ensure governance compliance.

---

# Feature Categories

## Raw Features

Collected directly from surveys.

Examples:

- Household Size
- Annual Income
- Crop Type
- Water Source
- Literacy Level
- Road Availability
- Electricity Access
- Internet Access

---

## Derived Features

Calculated from one or more raw features.

Examples:

- Income Per Family Member
- Dependency Ratio
- Agricultural Productivity Index
- Infrastructure Accessibility Score
- Healthcare Accessibility Score
- Education Opportunity Index
- Nutrition Risk Score
- Water Availability Score

---

## Aggregated Features

Generated by aggregating records.

Examples:

- Average Village Income
- Household Density
- Crop Diversity Index
- Average Healthcare Distance
- Average School Attendance
- Village Development Score

---

## Temporal Features

Derived from time-based observations.

Examples:

- Seasonal Rainfall Trend
- Crop Season
- Survey Age
- Historical Improvement Trend
- Previous Risk Trend

---

## Geographic Features

Derived using spatial information.

Examples:

- Distance to Primary Health Center
- Distance to School
- Distance to Water Source
- Elevation Category
- Flood Zone Indicator
- Drought Zone Indicator

# Missing Value Strategy

| Feature Type | Method |
|--------------|--------|
| Numerical | Median Imputation |
| Categorical | Mode Imputation |
| Time Series | Forward Fill |
| Geographic | Domain Rule |
| Derived Features | Recalculation |

---

# Outlier Treatment

Approved techniques include:

- IQR Method
- Z-Score
- Isolation Forest
- Winsorization
- Domain-based Thresholding

Outliers shall never be removed without documented justification.
