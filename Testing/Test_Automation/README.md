# Purpose

The Test Automation directory documents the test automation framework architecture, coding patterns, CI/CD integration pipelines, test runner configurations, and execution commands that drive continuous automated validation across unit, API, UI, and performance test layers.

---

# Scope

Test automation covers:
- Playwright End-to-End (E2E) UI Automation Framework (TypeScript)
- PyTest REST API Contract and Functional Test Framework (Python)
- k6 Distributed Performance and Load Testing Framework (JavaScript)
- Allure HTML Test Execution Reporting Infrastructure
